为什么全球都把钱花在’治病’而不是’防病’？

Tip本章 TL;DR
  • 全球预防性护理 (hc6) 占 CHE 中位数仅 ~3-5%，治疗性护理 (hc1) 普遍 > 50%。
  • 在 195 国 × 8 年的可观测样本中，几乎没有国家的预防占比超过 12%。
  • 财政紧缩 + 政治短视 = ONE Data 称之为 “Hidden Fragility” 的预防赤字。

5 3.1 治疗 vs 预防：散点的两极

GHED 的 hc1 (治疗性护理) 与 hc6 (预防性护理) 完整覆盖 2016–2023，样本量足以揭示一种近似 普世 的不对称模式。

Code
d_pc <- master_enriched |>
  dplyr::filter(.data$year == 2021,
                !is.na(.data$hc1_che), !is.na(.data$hc6_che)) |>
  dplyr::mutate(label = ifelse(.data$hc6_che > 9 | .data$hc1_che > 88,
                                .data$country_name, NA_character_))

p <- ggplot2::ggplot(d_pc, ggplot2::aes(.data$hc1_che, .data$hc6_che,
                                          colour = .data$continent)) +
  ggplot2::geom_point(alpha = 0.78, size = 2.6) +
  (if (requireNamespace("ggrepel", quietly = TRUE)) {
    ggrepel::geom_text_repel(ggplot2::aes(label = .data$label),
                             size = 3, max.overlaps = 18)
  } else {
    ggplot2::geom_text(ggplot2::aes(label = .data$label), size = 3)
  }) +
  ggplot2::geom_hline(yintercept = 6, linetype = "dashed",
                      colour = "grey50", linewidth = 0.4) +
  ggplot2::annotate("text", x = 90, y = 6.6, label = "WHO Recommendation 6%",
                    size = 3, colour = "grey40", hjust = 1) +
  ggplot2::scale_x_continuous(labels = scales::label_percent(scale = 1)) +
  ggplot2::scale_y_continuous(labels = scales::label_percent(scale = 1)) +
  scale_colour_ghs_continent() +
  labs_ghs(
    title    = "Prevention is Underfunded Almost Everywhere",
    subtitle = "横轴: 治疗 hc1 % \u00b7 纵轴: 预防 hc6 % \u00b7 大多数国家挤在 < 6% 区域",
    x = "治疗 hc1 (% of CHE)", y = "预防 hc6 (% of CHE)"
  ) +
  theme_ghs()
p

6 3.2 预防占比的 23 年走势

Code
d_hc6 <- master_enriched |>
  dplyr::filter(!is.na(.data$hc6_che)) |>
  dplyr::group_by(.data$year) |>
  dplyr::summarise(
    median_hc6 = stats::median(.data$hc6_che, na.rm = TRUE),
    p25 = stats::quantile(.data$hc6_che, 0.25, na.rm = TRUE),
    p75 = stats::quantile(.data$hc6_che, 0.75, na.rm = TRUE),
    .groups = "drop"
  )

ggplot2::ggplot(d_hc6, ggplot2::aes(.data$year, .data$median_hc6)) +
  ggplot2::geom_ribbon(ggplot2::aes(ymin = .data$p25, ymax = .data$p75),
                       fill = "#2E8B57", alpha = 0.18) +
  ggplot2::geom_line(linewidth = 1.4, colour = "#2E8B57") +
  ggplot2::geom_point(size = 2.5, colour = "#2E8B57") +
  ggplot2::geom_vline(xintercept = 2020, linetype = "dotted", colour = "grey50") +
  ggplot2::annotate("text", x = 2020.2, y = max(d_hc6$p75) * 0.98,
                    label = "COVID-19", hjust = 0, size = 3.2,
                    colour = "grey30") +
  ggplot2::scale_y_continuous(labels = scales::label_percent(scale = 1)) +
  labs_ghs(
    title    = "全球预防性护理 hc6 占比的演化",
    subtitle = "实线：中位数 \u00b7 阴影：IQR (25-75%)",
    x = NULL, y = "hc6 (% of CHE)"
  ) +
  theme_ghs()

疫情悖论：你或许期望 COVID 之后预防占比上升 —— 但事实恰恰相反，2021-2022 年中位数较 2019 年下降了约 0.4 个百分点。急性医疗挤压了预防资源。

7 3.3 谁把预防做得相对好？

Code
master_enriched |>
  dplyr::filter(.data$year == 2021, is.finite(.data$hc6_che)) |>
  dplyr::arrange(dplyr::desc(.data$hc6_che)) |>
  dplyr::slice_head(n = 15) |>
  dplyr::transmute(
    国家 = .data$country_name,
    大洲 = .data$continent,
    `预防 hc6 (%)` = round(.data$hc6_che, 2),
    `治疗 hc1 (%)` = round(.data$hc1_che, 2),
    `OOPS (%)` = round(.data$hf3_che, 2)
  ) |>
  knitr::kable(caption = "2021 年预防占比最高的 15 国")

上榜国家有几个共性：要么是传染病防控压力大的国家（如卢旺达、马拉维），要么是公共卫生体系成熟的北欧国家（如芬兰、英国、加拿大）。中间的中等收入国家反而最缺预防投入。

8 3.4 用 Waffle 图直观感受比例

plot_waffle_purpose(master_enriched, year_focus = yr_max,
                    isos = c("CHN", "USA", "RWA"))

每一格代表 1% 的 CHE。三国对比：

  • 美国：治疗几乎填满整个网格；
  • 中国：治疗仍主导，预防可见但不显眼；
  • 卢旺达：因为传染病防控国策与外援导向，预防格子明显比平均高。

9 3.5 为什么会这样？

Warning

预防的政治经济学难题：

  • 预防的回报周期长 (10–30 年)，政治周期短 (3–5 年)。
  • 预防的受益对象是统计意义上的 未发病人群，缺乏直接政治游说。
  • 财政紧张时，预防最容易被砍 —— ONE Data 报告称之为 “Hidden Fragility”。
  • COVID 后并未自动出现 预防觉醒，反倒被急诊与重症资源进一步挤压。
