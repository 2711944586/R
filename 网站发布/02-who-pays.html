政府、私人、外援 —— 全球三方的角力

Tip本章 TL;DR
  • 2023 年全球各国 OOPS 占 CHE 的 均值约 30.3%，但分布极偏：极端高的国家可达 70%+，极端低的国家不到 10%。
  • 政府主导 (GGHE-D > 60%) 与较低 OOPS 高度负相关，这与 UHC 的核心政策目标一致。
  • 外援 (EXT) 在最贫困国家曾承担 30-40% 的卫生支出，近 10 年系统性下降，意味着本土财政能力必须同步崛起。

4 2.1 OOPS：居民自付的世界版图

Code
world_sf <- tryCatch(load_world_sf(scale = "medium", simplify_keep = 0.08),
                     error = function(e) NULL)
if (!is.null(world_sf)) {
  plot_world_choropleth(master_enriched, world_sf,
                        indicator_col = "hf3_che", year_focus = yr_max,
                        title = sprintf("OOPS 占 CHE 比例 \u00b7 %d", yr_max),
                        subtitle = "颜色越深 \u00b7 居民自付负担越高 \u00b7 灰色为缺失")
}

热区：撒哈拉以南非洲、南亚、中亚以及部分加勒比国家颜色最深；冷区：欧盟核心国、澳新、加拿大颜色最浅。颜色梯度几乎与 人均 GDP 倒序 重合。

5 2.2 OOPS 排行榜：极端两端 15 国

Code
plot_oops_ranking(master_enriched, year_focus = yr_max, top_n = 15,
                  title = sprintf("Top/Bottom 15 OOPS Reliance \u00b7 %d",
                                   yr_max))

排行榜的两个尾巴：

  • 高位：阿富汗、孟加拉、也门、苏丹等，OOPS 普遍 > 60% —— 这意味着每生一场病，居民自掏腰包的金额能轻易拖垮一个家庭。
  • 低位：荷兰、卢森堡、法国、德国 —— 全民医保 + 强制社会保险使 OOPS < 12%。

6 2.3 收入组脊线：分布的厚尾故事

Code
if (requireNamespace("ggridges", quietly = TRUE)) {
  plot_oops_ridges_income(master_enriched, year_focus = yr_max)
}

脊线图比箱线图更能传达：

  • 低收入 组分布右偏，“长尾” 集中在 50-70% 区间。
  • 高收入 组分布左偏、几乎全部 < 25%。
  • 中等收入组在 20-40% 区域形成 双峰，对应国内不同医疗体系子样本。

7 2.4 OOPS 的 23 年趋势

d_oops_trend <- master_enriched |>
  dplyr::filter(!is.na(.data$continent), !is.na(.data$hf3_che)) |>
  dplyr::group_by(.data$year, .data$continent) |>
  dplyr::summarise(median_oops = stats::median(.data$hf3_che, na.rm = TRUE),
                   .groups = "drop")

ggplot2::ggplot(d_oops_trend, ggplot2::aes(.data$year, .data$median_oops,
                                             colour = .data$continent)) +
  ggplot2::geom_line(linewidth = 1.3) +
  ggplot2::geom_point(size = 1.5, alpha = 0.7) +

    title    = "OOPS by Continent: 23-year Trend",
    subtitle = "中位数 \u00b7 大多数大洲下降但分化未消除",
    x = NULL, y = "OOPS (% of CHE)"
  ) +
  theme_ghs()

8 2.5 三源到方案的桑基图

Code
plot_sankey_static(master_enriched, year_focus = yr_max)

桑基图把”政府/私人/外援”这一资金来源 (revenue) 维度，与”hf1/hf2/hf3/hf4/hfnec”筹资方案 (scheme) 维度连起来：

  • 政府收入主要流向 强制公共/社会保险 (hf1)；
  • 私人收入分别流向 自愿保险 (hf2) 与 居民自付 OOPS (hf3)；
  • 外援几乎全部流向 hf1（政府）或 hf4（NPISH/雇主），极少形成 hf3。

9 2.6 政策启示

Important
  • OOPS > 50% 几乎是因病致贫风险的高保真代理变量。
  • 政府份额 增加是降低 OOPS 的最直接政策杠杆。
  • 外援依赖 的国家需要 转换 而非 戒断 —— 短期补贴必要、长期本土能力关键。
