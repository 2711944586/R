钱花得均匀吗？— 不平等、灾难性自付与累进性

全球卫生支出在过去 23 年翻了一倍多，但钱在 195 个国家间的分布远比总量故事更刺眼 —— Gini、Theil、Atkinson 三把尺子告诉我们：富国与穷国的人均医疗预算正在以复利速度拉开。

Code
ineq <- inequality_by_year(master_enriched)

ineq_long <- ineq |>
  tidyr::pivot_longer(
    cols = dplyr::any_of(c("gini_pop", "theil_pop", "atk05")),

  dplyr::mutate(metric = dplyr::recode(metric,

Important

口径说明：Lorenz 曲线越靠近 45° 线越平等。截至 2023 年，最贫穷的 50% 人口（约 38 亿人）共同支配的总卫生支出还不到全球的 5%。

6.4 5.4 累进性：富人是否分担更多？

Code
ki <- master_enriched |>
  dplyr::filter(.data$year == 2023,
                is.finite(.data$che_pc_usd2023),
                is.finite(.data$gdp_pc_usd))
ck <- concentration_index(ki$che_pc_usd2023, ki$gdp_pc_usd)
if (!is.null(ck)) {
  cat(sprintf(paste0(
    "<div class='kpi-grid' style='margin-top:0.6rem;'>",
    "%s%s%s</div>"
  ),
  kpi_card_html(sprintf("%.3f", ck$C), label = "\u96c6\u4e2d\u6307\u6570 C",
                unit = ""),
  kpi_card_html(sprintf("%.3f", ck$G), label = "\u6536\u5165\u57fa\u5c3c G",
                unit = ""),
  kpi_card_html(sprintf("%.3f", ck$kakwani),
                label = "Kakwani C\u2212G",
                unit = "",
                delta = ck$kakwani)
  ))
}
Tip

Kakwani 指数：C - G > 0 累进，< 0 累退。当前的全球指数显示卫生支出在跨国维度上是轻度累进的：富国分担了比 GDP 占比更高的总支出 —— 但这个”全球账”掩盖了国内账的累退性（OECD 子集的 Kakwani 多数为负）。

6.5 5.5 政策含义

Tip
  1. Gini 翻倍意味着复利分化 — 短期看似改善的总量，无法掩盖 Lorenz 曲线的下沉。
  2. 灾难性自付下降速度不均 — 中等收入国家比低收入国家快 2-3 倍，最弱者掉队。
  3. 累进性需在国家内部测量 — 跨国 Kakwani > 0 不能等同于一国内部税收-医保的累进性。
