同样的钱，能买到几年寿命？— DEA 视角

2019 年阿曼人均医疗支出 $726，HALE（健康预期寿命） 64.5 年； 同年美国花了 $11,072，HALE 66.1 年。 多花 15 倍的钱，多买到 1.6 年健康寿命。 本章用一个简化的 DEA 效率前沿，找出谁是钱买寿命最高效的国家。

8.1 7.1 简化 DEA：每美元买几年 HALE

Code
master_panel <- build_master_panel(master_enriched, external_data)
dea <- fit_dea_efficiency(master_panel, year_focus = 2019)

if (!is.null(dea) && nrow(dea)) {
  topn <- dea |> dplyr::arrange(dplyr::desc(.data$eff_crs)) |>
    dplyr::slice_head(n = 30)

  ggplot2::ggplot(topn, ggplot2::aes(.data$che_pc_usd2023,
                                       .data$HALE,
                                       size = .data$eff_crs,
                                       colour = .data$continent)) +
    ggplot2::geom_point(alpha = 0.75) +
    ggrepel::geom_text_repel(
      data = dplyr::slice_head(topn, n = 12),
      ggplot2::aes(label = .data$country_name),
      family = get_brand_fonts()$serif, size = 3.4,
      max.overlaps = 20, segment.colour = "grey60") +
    ggplot2::scale_x_continuous(labels = scales::label_dollar(),
                                 trans = "log10") +
    ggplot2::scale_size_continuous(name = "DEA \u6548\u7387",
                                   range = c(2, 8)) +
    scale_colour_brand_continent() +
    labs_news(
      title    = "\u7b80\u5316 DEA \u524d\u6cbf \u00b7 2019",
      subtitle = "\u52a0\u52d2\u6bd4\u3001\u6cf0\u56fd\u3001\u9a6c\u6765\u897f\u4e9a\u662f\u552f\u4e00\u8d2d\u4e70\u8d8525\u5e74\u5bff\u547d/\u7f8e\u5143\u7684\u5176\u4ed6\u9009\u9879",
      x = "\u4eba\u5747 CHE (USD, log)", y = "HALE (\u5e74)"
    )
}

Note

DEA 效率前沿衡量的是 相对 概念 —— 在样本内，没人能在同等支出下做得更好。它不意味着低支出国家”医疗更好”；而是揭示给定预算约束下的资源利用质量。哥斯达黎加用 $1,400/人 实现 HALE 66.5，而 OECD 中位 $5,000/人 才能达到 67.5 —— 制度设计的回报远超钱本身。
