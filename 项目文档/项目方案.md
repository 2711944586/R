### 1.3 数据合规与质量

- **变量名锁定**：`financing_schemes` / `health_spending` / `spending_purpose` 全程不改。
- **离线优先**：所有外部数据在 `派生数据/外部数据/*.parquet` 提交进 git（小于 100 MB），CI 不联网也能 build。
- **质量校验**（在 `程序/02_clean.R` 与 `程序/16_data_quality.R`）：
  - `hf1+hf2+hf3+hf4+hfnec ≈ 100`（容差 ±5pp，覆盖率 ≥ 95%）
  - `gghed_che + pvtd_che + ext_che ≈ 100`（同上）
  - `_usd2023` 与 `_che` 比例自洽：`indicator_usd2023 / che_usd2023 × 100 ≈ indicator_che`
  - 缺失模式：MCAR / MAR / MNAR 诊断表（`naniar::miss_var_summary` + Little's MCAR test）
  - 异常值：温和 IQR + 严格 3σ 双标准

## 3. 30 个研究问题（6 大主题）

每个问题产出 **≥ 2 张图 + 1 段结论 + 1 个 widget + 1 段方法说明**。

|---|---|---|---|
