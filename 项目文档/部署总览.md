# 部署使用手册 · Global Health Spending 20× 项目

> 三件套部署：**Quarto Pages** + **Shiny Cloud** + **Docker**。
> 全部基础设施都在仓库内，对评阅老师友好（不需要本地 R 环境也能玩）。

---

## A. 本地一键运行（Windows / macOS / Linux）

### A.1 装包 + 跑流水线

```r
## 在 R 中
source("安装依赖.R")           # 安装全部依赖（一次性，约 15 min）
targets::tar_make()         # 构建 派生数据/处理结果/*.rds  cache
```

或者跳过 `targets`：

```r
source("开发脚本/语法检查.R")   # 跑通数据加载 + 3 张图 sanity check
```

### A.2 一键产出 25+ 静态图、12 个交互 widget、所有模型表

```bash
Rscript 开发脚本/生成分析输出.R all       # figures+widgets+models
Rscript 开发脚本/生成分析输出.R figures   # 仅静态图
Rscript 开发脚本/生成分析输出.R widgets   # 仅交互 widget
Rscript 构建.R models                # 仅模型 + CSV
```

### A.3 启动 Shiny 仪表盘

```r
shiny::runApp("仪表盘", port = 3838, host = "127.0.0.1")
```

### A.4 渲染 Quarto 叙事书

```bash
quarto render 报告书          # 渲染到 网站发布/
```

## B. Docker 一键启动（无需本地 R）

```bash
docker build -f 部署配置/Dockerfile -t ghs-dashboard .
docker run -p 3838:3838 ghs-dashboard
# → 浏览器访问 http://localhost:3838
```

或者用 compose 一次拉起 dashboard + book + RStudio Server：

```bash
docker compose -f 部署配置/docker-compose.yml up -d
# dashboard:  http://localhost:3838
# book:       http://localhost:8080
# rstudio:    http://localhost:8787  (user=rstudio / pass=ghs20241334)
```

## C. CI/CD 自动部署

### C.1 GitHub Actions Workflow 列表

| Workflow                      | 触发                                  | 产物                            |
| ----------------------------- | ------------------------------------- | ------------------------------- |
| `R-CMD-tests.yml`             | push / PR                             | testthat 报告 + 语法检查        |
| `deploy.yml`                  | push / 手动触发                       | GitHub Pages + shinylive + shinyapps.io |

### C.2 GitHub Pages 部署条件

1. 仓库设置 → Pages → Source 选 **GitHub Actions**。
2. 推到 `main` 分支后，`deploy.yml` 自动跑 `quarto render 报告书` →
   产物上传到 `网站发布/` → Pages 自动发布。
3. 部署 URL 形如 `https://<owner>.github.io/<repo>/`。

### C.3 shinyapps.io 部署条件

需要在仓库 **Settings → Secrets and variables → Actions** 加入三个 Secret：

| Secret              | 值                                                                       |
| ------------------- | ------------------------------------------------------------------------ |
| `SHINYAPPS_NAME`    | shinyapps.io 用户名（注册后从 Account → Tokens 复制）                    |
| `SHINYAPPS_TOKEN`   | rsconnect token                                                          |
| `SHINYAPPS_SECRET`  | rsconnect secret                                                         |

注册 + 拿 token：

```r
install.packages("rsconnect")
rsconnect::setAccountInfo(name = "<USER>",
                          token  = "<TOKEN>",
                          secret = "<SECRET>")
# 之后 token/secret 写入仓库 Secrets 即可
```

`deploy.yml` 推送 `仪表盘/**` 后自动调用 `rsconnect::deployApp()`。

## D. 故障排查 Cheatsheet

| 现象                                         | 解释 / 解决                                                                  |
| -------------------------------------------- | ---------------------------------------------------------------------------- |
| `here` 包加载失败                            | 中文路径 + `here::here()` 在 onLoad 调 `normalizePath` 抛错；`proj_root()` 已降级 |
| Quarto 渲染中文字体显示 ☐                    | `fonts-noto-cjk` 已写入 Dockerfile + Pages workflow                          |
| `sf` / `terra` 编译失败                      | 系统包 `libgdal-dev libgeos-dev libproj-dev libudunits2-dev`                 |
| Shiny 部署报缺 `wbstats`                     | 仪表盘只读缓存 `派生数据/处理结果/master_enriched.rds`，不需要在线下 WDI       |
| `prophet` 安装慢                             | 在 Docker 中跳过；项目内 forecast 用 `forecast::auto.arima` 已足够          |
| GHA 跑出超时                                 | `setup-r-dependencies` 缓存层设置不当；删 `.github/cache` 重跑              |
