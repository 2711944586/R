## 五、Rmd 完成度审核

`课程提交/庄颂_20241334.Rmd` 目前定位清晰：它是课程要求的入口文件，调用 `generate_static_showcase()` 生成同源 HTML。这种方式比在 Rmd 中堆大量 chunk 更稳定，也避免 Rmd 与静态页内容不一致。

建议下一步把 Rmd 再扩展为“提交说明 + 审计摘要 + 一键生成 + 复现命令 + sessionInfo”的轻量报告，而不是把 2000 行静态 HTML 逻辑搬回 Rmd。

## 八、安全建议

shinyapps.io token 和 secret 属于敏感凭据。它们不应出现在任何 `.R`、`.Rmd`、`.yml`、`.md` 或提交历史中。建议在 shinyapps.io 控制台轮换本次聊天中暴露过的 token，并只把新值写入 GitHub Repository Secrets：`SHINYAPPS_NAME`、`SHINYAPPS_TOKEN`、`SHINYAPPS_SECRET`。
