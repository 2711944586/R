### 🐛 9 个关键 bug 修复

每一个都阻塞渲染，按发现顺序：

1. **`here::here()` 在 报告书/ 多套一层** — `_quarto.yml` 触发 here 的 `is_quarto_project` detector，把 `报告书/` 当成项目根 → `here::here("报告书", "_setup.R")` 返回 `报告书/报告书/_setup.R` 不存在
   - **修复**：改用 `rprojroot::find_root(rprojroot::has_file("DESCRIPTION"))` 锚定 R 包标记
   - 影响 14 个 .qmd 文件 setup chunk → `开发脚本/修复报告项目根.R`

2. **`setwd("..")` 触发 knitr in_dir 警告** — `_setup.R` 内部切换 cwd 让 knitr 报 `You changed the working directory ... It will be restored`
   - **修复**：`报告书/_setup.R` 全部改用绝对路径（`file.path(.proj_root, ...)`），不再 setwd

3. **`fit_dea_efficiency()` 缺 HALE 列时硬错** — 当外部 GHO/GBD 数据未拉取时 `master_panel` 没 HALE 列，函数仍尝试 `.data$HALE` 触发 `data_pronoun_not_found`
   - **修复**：函数开头加列存在检查，缺则 `return(NULL)`

4. **`\uXXXX = value` 裸参数名** — R 不能解析非字符串里的 `\u` escape
   - **修复**：5 处 → `` `中文` = value ``（开发脚本/修复裸中文参数.R）

5. **`` `…\uXXXX…` `` backtick 内 unicode escape** — R 4.x 显式禁止 `\uxxxx sequences not supported inside backticks`
   - **修复**：13 处 → `` `真实中文` ``（开发脚本/修复反引号中文.R）

6. **ch05 `inequality_by_year` 列名错** — chunk 用 `gini_w/theil_t/atkinson_05`，函数返回 `gini_pop/theil_pop/atk05`
   - **修复**：手工对齐列名

7. **dplyr 在 sf 对象上 left_join 失败** — `library(sf)` 没在 `_setup.R` 里 attach，S3 方法未注册
   - **修复**：`_setup.R` 添加 `library(sf)`

8. **`labs_ghs()` 不接受 `colour=NULL` 等额外参数**
   - **修复**：`程序/06_plot_theme.R` 加 `...` 参数透传给 `ggplot2::labs()`

9. **Quarto cache 阻碍验证** — 错误的 chunk 被 cached
   - **修复**：每次大改后清 `*_cache/`、`*_files/`、`.quarto/`
