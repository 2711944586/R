# 方法手册

本文档记录本项目 14 个核心 findings 的研究问题、数据口径、方法、可复核产物和局限。它服务于三类复核场景：

- **课程评阅**：快速确认每个结论来自哪一张图、哪一个模型表和哪一段代码。
- **复现实验**：按统一命令重新生成数据、特征表、模型、图表、交互组件和静态页。
- **后续维护**：在扩展或调整分析时，保持数据口径与方法的一致性。

## 1. 数据与版本口径

| 项目 | 口径 |
|---|---|
| 主数据 | WHO Global Health Expenditure Database 三张原始表，经 `程序/01_io.R`、`程序/02_clean.R`、`程序/03_enrich.R` 生成 `master_enriched.rds`。 |
| 时间范围 | 2000–2023；少数外部变量取决于 WDI / GHO / IMF 缓存覆盖。 |
| 货币口径 | `che_usd2023` 与 `che_pc_usd2023` 使用 2023 USD 不变价口径。 |
| 核心筹资变量 | `gghed_che`、`pvtd_che`、`ext_che`、`hf3_che` 等均为占 CHE 的百分比。 |
| 健康结果 | `life_exp` 与 `u5mr` 来自 WDI 缓存或增强面板；健康预期寿命、UHC 指标来自 WHO GHO 缓存。 |
| 统一特征表 | `Rscript 构建.R features` 生成 `feature_mart_country_year.csv` 与 `feature_dictionary.csv`。 |
| 静态展示页 | `Rscript 构建.R submission` 生成 `课程提交/庄颂_20241334.html` 与 `网站发布/index.html`。 |
| 质量门禁 | `Rscript 构建.R quality` 检查语法、图像、链接、widget、secret、文案、体积、Shiny bundle 和 README 一致性。 |

## 2. 通用方法约束

| 约束 | 执行方式 |
|---|---|
| 描述优先 | 本项目多数 finding 是描述性或预测性分析，不把相关关系写成因果效应。 |
| 加权说明 | 涉及全球或跨国均值时明确区分人口加权、简单平均和总量加总。 |
| 缺失处理 | 图表和模型只使用对应变量可用的国家年份；不静默删除异常点，必要时在图注或局限中说明。 |
| 不确定性 | 回归、ARIMA、情景模拟和效率前沿均报告置信区间、预测区间或残差解释。 |
| 复核入口 | 每个 finding 至少绑定一个脚本入口、一个图表或模型表、一个局限说明。 |
| 术语一致 | OOPS 指居民自付，GGHED 指政府强制筹资，PVTD 指国内私人筹资，EXT 指外部援助。 |

## 3. Findings 方法矩阵

### F1 全球长期趋势：扩张但分化

| 要素 | 内容 |
|---|---|
| 研究问题 | 2000–2023 年全球卫生支出在总量与结构上如何演变。 |
| 数据口径 | 按年份汇总 `che_usd2023`，并计算 GGHED、PVTD、EXT 的结构变化。 |
| 方法 | 构造全球年度面板，计算总额、年化增速、人均 CHE 和三类资金来源份额，绘制堆叠面积与大洲流变图。 |
| 代码入口 | `程序/07_plot_static.R::plot_source_area()`；静态页 F1 模块位于 `程序/21_static_showcase.R`。 |
| 主要产物 | `01_global_sources_area.png`、`v2_continent_stream.png`、`02_highlight_ts.html`。 |
| 局限 | USD2023 不变价与各国本币预算口径不同；筹资份额定义在年代间可能调整；该 finding 不识别因果。 |

### F2 谁在付钱：从 OOPS 看财务保护

| 要素 | 内容 |
|---|---|
| 研究问题 | 政府、居民自付、私人筹资和外部援助分别承担多少卫生财务风险。 |
| 数据口径 | 使用 `hf3_che` 表示 OOPS，占 CHE 百分比；同时读取 `gghed_che`、`pvtd_che`、`ext_che`。 |
| 方法 | 在最近年份截面中排序 OOPS Top / Bottom 国家，结合 GGHED 与 EXT 图识别财务保护薄弱国家。 |
| 代码入口 | `程序/07_plot_static.R::plot_oops_ranking()`；静态页 F2 模块位于 `程序/21_static_showcase.R`。 |
| 主要产物 | `02_oops_ranking_2023.png`、`v2_fiscal_ghe_share.png`、`v2_aid_dependency.png`、`12_reactable_rank.html`。 |
| 局限 | OOPS 依赖住户支出和成本分摊调查，低收入国家可能低估；外援在紧急期跳动较大；财务保护还受医保覆盖和财政制度影响。 |

### F3 公平性：Gini / Theil / Atkinson

| 要素 | 内容 |
|---|---|
| 研究问题 | 跨国人均卫生支出不平等是否下降，以及下降发生在哪些分布部位。 |
| 数据口径 | 使用 `che_pc_usd2023`，优先以 `pop` 做人口加权。 |
| 方法 | 对每年国家截面计算 Gini、Theil-T、Atkinson(0.5/1.0)，并用 Lorenz 曲线对比 2000 与 2023。 |
| 代码入口 | `程序/04_metrics.R::inequality_by_year()`、`gini_weighted()`、`theil_t()`、`atkinson()`。 |
| 主要产物 | `11_inequality_timeseries.png`、`v2_equity_lorenz.png`、`v2_equity_indices.png`、`ineq_panel.csv`、`07_inequality.html`。 |
| 局限 | 跨国不平等不等同于国内不平等；重尾分布会影响指数估计；Atkinson 结果依赖不平等厌恶参数。 |

### F4 COVID 冲击：财政托底与负担转移

| 要素 | 内容 |
|---|---|
| 研究问题 | COVID-19 期间哪些国家扩大了卫生支出，哪些国家把压力转移给居民自付。 |
| 数据口径 | 以 2019 为基线，以 2020–2022 均值为冲击期；比较 CHE、OOPS 和 GGHED 变化。 |
| 方法 | 逐国计算 `che_delta_pct`、`oops_delta_pp`、`gghed_delta_pp`，用哑铃图和散点图呈现冲击方向。 |
| 代码入口 | `程序/04_metrics.R::covid_shock()`；静态页 F4 模块位于 `程序/21_static_showcase.R`。 |
| 主要产物 | `v2_covid_dumbbell.png`、`09_covid_scatter.png`、`v2_w_oops_heatmap.html`。 |
| 局限 | 2020–2022 均值只捕捉短期冲击；部分国家近年数据仍可能修订；没有拆分报销、补贴和交叉补偿。 |

### F5 β-收敛：低起点国家是否追赶

| 要素 | 内容 |
|---|---|
| 研究问题 | 起点较低的国家是否在 2000–2023 年获得更快的人均 CHE 增速。 |
| 数据口径 | 每国 2000 与 2023 的 `che_pc_usd2023`，以可用国家为样本。 |
| 方法 | 计算年化对数增速，回归 `growth ~ log_start + continent`，以 `log_start` 系数判断 β-收敛方向。 |
| 代码入口 | `程序/05_models.R` 的 β-收敛模型段；静态页 F5 模块位于 `程序/21_static_showcase.R`。 |
| 主要产物 | `23_beta_convergence.png`、`beta_panel.csv`、`v2_w_gapminder_bubble.html`。 |
| 局限 | β-收敛描述平均趋势，不代表低位国家绝对差距已消失；大洲固定效应不能替代制度、冲突和财政变量。 |

### F6 GDP 与卫生支出弹性：双向固定效应

| 要素 | 内容 |
|---|---|
| 研究问题 | 一国人均 GDP 增长 1% 时，人均卫生支出大约增长多少。 |
| 数据口径 | `log(che_pc_usd2023)` 与 `log(gdp_pc_usd)` 的国家年份面板。 |
| 方法 | 使用双向固定效应模型 `log_che ~ log_gdp | iso3_code + year`，按国家聚类标准误。 |
| 代码入口 | `程序/05_models.R` 面板 FE 模型段；输出整理到 `panel_fe_tidy.csv`。 |
| 主要产物 | `panel_fe_tidy.csv`、`v2_w_splom.html`。 |
| 局限 | 固定效应不能消除时间变化的遗漏变量；弹性估计不是因果估计；聚类标准误和样本窗口会影响显著性。 |

### F7 PCA 与聚类：四种筹资 archetype

| 要素 | 内容 |
|---|---|
| 研究问题 | 国家在 GGHED、PVTD、EXT、OOPS 构成空间中能否形成稳定类型。 |
| 数据口径 | 最近年份的筹资结构截面，变量中心化并标准化。 |
| 方法 | 对筹资变量做 PCA，取前两主成分，再使用 k-means(k=4, nstart=25) 形成四类国家组合。 |
| 代码入口 | `程序/05_models.R` PCA 与聚类模型段。 |
| 主要产物 | `12_pca_cluster_2022.png`、`22_inequality_pca.png`、`v2_w_country_network.html`。 |
| 局限 | PCA 载荷依赖变量选择；k=4 是解释性分类，不是唯一分类；截面聚类不能说明动态转移。 |

### F8 ARIMA 预测：四国 2024–2028

| 要素 | 内容 |
|---|---|
| 研究问题 | 中国、美国、印度、巴西的人均卫生支出短期路径可能如何延续。 |
| 数据口径 | 各国 2000–2023 年 `che_pc_usd2023` 单变量时间序列。 |
| 方法 | 对每个国家拟合 `auto.arima`，输出 5 年点预测和 80% / 95% 预测区间。 |
| 代码入口 | `程序/05_models.R` ARIMA 预测段。 |
| 主要产物 | `24_forecast_fan.png`、`forecast_5y.csv`、`06_forecast_subplot.html`。 |
| 局限 | ARIMA 不使用 GDP、财政、人口老龄化等驱动变量；外推期越长区间越宽；不包含重大冲击情景。 |

### F9 外援依赖：EXT 与本土财政能力

| 要素 | 内容 |
|---|---|
| 研究问题 | 哪些国家卫生财务系统仍显著依赖外部援助，且是否同时存在高 OOPS。 |
| 数据口径 | `ext_che` 为外部援助占 CHE 百分比，结合 `gghed_che`、`hf3_che` 与 `che_pc_usd2023`。 |
| 方法 | 在最近年份排序 EXT 份额，识别 EXT > 20% 的高依赖国家，并与 OOPS / GGHED 联合解释。 |
| 代码入口 | `程序/21_static_showcase.R` F9 模块；图表由 `程序/22_plots_extra.R` 等扩展图集生成。 |
| 主要产物 | `v2_aid_dependency.png`、`17_ext_density.png`、`v2_w_sankey_flows.html`。 |
| 局限 | 外援统计受项目周期和人道响应影响；GHED 对双边项目和专项资金口径存在差异；EXT 份额不代表资金效率。 |

### F10 效率前沿：同样资金下谁产出更高

| 要素 | 内容 |
|---|---|
| 研究问题 | 给定人均 CHE 后，哪些国家预期寿命或 U5MR 表现高于模型预测。 |
| 数据口径 | 最近年份 `che_pc_usd2023`、`life_exp`，扩展图中也使用 U5MR 和 HALE。 |
| 方法 | 拟合 `life_exp ~ log(che_pc_usd2023)`，以正残差识别高效率国家；另用 DEA 图作互补呈现。 |
| 代码入口 | `程序/12_advanced_models.R::fit_dea_efficiency()`；静态页 F10 模块位于 `程序/21_static_showcase.R`。 |
| 主要产物 | `v2_efficiency_dea.png`、`v2_outcomes_elasticity.png`、`v2_w_scenarios.html`。 |
| 局限 | 预期寿命受环境、教育、生活方式和人口结构影响；单输入单输出 DEA 只是简化前沿；残差不是效率的完整度量。 |

### F11 排名变迁：后发上升与相对下滑

| 要素 | 内容 |
|---|---|
| 研究问题 | 2000–2023 年哪些国家人均 CHE 排名显著上升，哪些国家相对下滑。 |
| 数据口径 | 2000、2010、2023 三个截面的 `che_pc_usd2023` 排名。 |
| 方法 | 对每年国家截面按人均 CHE 降序排名，计算 `Δrank`，并用 bump chart 展示 Top 25。 |
| 代码入口 | `程序/21_static_showcase.R` F11 模块；扩展图由 `程序/22_plots_extra.R` 生成。 |
| 主要产物 | `v2_rank_change.png`。 |
| 局限 | 排名变动只反映相对位置，不等于绝对支出增长；汇率与价格修正后仍可能有跨国比较误差。 |

### F12 预期寿命弹性：资金与寿命的对数关系

| 要素 | 内容 |
|---|---|
| 研究问题 | 人均卫生支出提升与预期寿命提升之间的边际关系如何变化。 |
| 数据口径 | 最近年份 `life_exp` 与 `che_pc_usd2023`。 |
| 方法 | 拟合 `life_exp ~ log(CHE_pc)`，用斜率乘以 `ln(2)` 解释人均资金翻倍对应的寿命变化。 |
| 代码入口 | `程序/21_static_showcase.R` F12 模块；相关图由扩展图集生成。 |
| 主要产物 | `v2_lifeexp_elasticity.png`、`v2_corr_matrix.png`。 |
| 局限 | 拟合为描述性关系；寿命受多维因素影响；COVID 后最近年份的寿命指标仍有扰动。 |

### F13 SDG-3 进展：寿命与儿童存活

| 要素 | 内容 |
|---|---|
| 研究问题 | 哪些国家在 2000–2023 年获得最多寿命增量和 U5MR 改善。 |
| 数据口径 | 2000 与 2023 的 `life_exp`、`u5mr`，以及 GGHED、OOPS、CHE_pc 等辅助轴。 |
| 方法 | 计算寿命增加量与 U5MR 下降量，绘制 Top 国家条形图和多轴雷达图。 |
| 代码入口 | `程序/21_static_showcase.R` F13 模块；扩展图由 `程序/22_plots_extra.R` 生成。 |
| 主要产物 | `v2_sdg3_progress.png`、`v2_sdg3_radar.png`。 |
| 局限 | 仅覆盖 SDG-3 的代表性健康结果；未纳入传染病、慢病、伤害、心理健康等完整指标。 |

### F14 极值与变点：跳跃、停滞与冲击年份

| 要素 | 内容 |
|---|---|
| 研究问题 | 哪些国家 23 年间人均 CHE 增长最快或最慢，全球增速是否存在变点。 |
| 数据口径 | 2000 与 2023 的 `che_pc_usd2023`，并限制起点不低于 50 美元以降低倍数误导。 |
| 方法 | 计算 2023/2000 倍数并排序两端国家；对全球 CHE 年增速使用 changepoint 检测单变点。 |
| 代码入口 | `程序/21_static_showcase.R` F14 模块；扩展图由 `程序/22_plots_extra.R` 生成。 |

## 7. 缺失值与变量完整性策略

本项目所有涉及缺失值（NA）的处理都遵循以下原则，避免"悄悄填充"引入虚假结构。

### 7.1 原始层（`原始数据/`）
- WHO GHED 的三张 CSV（financing_schemes / revenue_sources / functions）原封不动保留。原始 NA 不回填、不删除。
- 如个别国家 / 年份该文件缺席（例：`WLD`、`EU`、某些历史拆分实体），`01_io.R::load_ghs()` 会给出 warning 但不中断流水线。

### 7.2 清洗层（`02_clean.R`、`03_enrich.R`）
- **只做识别与标准化，不做缺失插补**：
  - `iso3_code` 缺失时用 `countrycode::countryname()` 回填；若仍缺失，记入 `countrycode_unmatched.csv`。
  - `continent` / `income_group` 通过 `countrycode` 匹配；少量历史实体（`YUG`, `SUN` 等）在 `程序/03_enrich.R` 内的手动映射表补齐。
- **数值变量不做均值 / 中位数插补**。如某年某国 `hf3_che` 缺失，所有后续表格里该 cell 仍保留 NA。

### 7.3 衍生指标层（`04_metrics.R`、`05_models.R`、`12_advanced_models.R`）
- **成列筛选而非填充**：例如 `inequality_by_year()` 对每年度先 `is.finite() & pop > 0` 过滤，再计算 Gini / Theil / Atkinson；
- **聚类 / PCA / DEA** 统一用 `tidyr::drop_na()` 在模型 call 前做"行级"删除，并在输出对象里记录 `n_used / n_total`；
- **预测** (`auto.arima`) 用的是 `ts()` 单国序列，允许序列中段缺失（作为 missing data），但要求前后至少 10 个非缺失点；
- **β-收敛 / 面板 FE** 两端年份都有观测才纳入，缺失国家在对应表中标注为 `excluded=TRUE`。

### 7.4 可视化层（`07_plot_static.R` 等）
- ggplot 图在绘制前显式过滤 `is.finite()`，并在 caption 中标注 `n = XXX`；
- 地图 choropleth 对 NA 国家使用 `#f0f0f0` 灰底 + tooltip "无数据"；
- 预测 fan chart 若点预测为 NA，会退回"仅展示历史"。

### 7.5 规则汇总
- 所有 NA 在派生表中**保留为 NA**，不写 0 / -1 / 'N/A' 字符串；
- 特征表 `派生数据/处理结果/feature_mart_country_year.csv` 保留完整面板（195 国 × 24 年 × 所有变量），**缺失即 NA**；
- `feature_dictionary.csv` 的 `missingness` 列给每个变量一个"有效样本量 / 总样本量"比例；
- 每个 finding 的图注中都明确给出"n = XXX 个国家" / "样本年份 = YYYY–YYYY"。

### 7.6 已知数据问题
- **2020–2023 修订风险**：GHED 每 12 个月会修订最近 2–3 年数据，阅读预测与近年趋势时应留有谨慎；
- **小岛屿国数据断档**：基里巴斯、汤加、瑙鲁等国 `che_pc_usd2023` 在 2010 前有长年断档，已在静态页 F1/F11 明确说明；
- **高冲击国**：委内瑞拉 / 叙利亚 / 乌克兰近年数据由 WHO 估计，跨国比较需谨慎；本报告所有排名都在默认样本内保留它们，但在 finding 深度块里单独注明。
