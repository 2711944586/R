## 0. 升级宗旨（Charter）

1. **内容三倍**：静态图、交互组件、findings、Shiny 模块、模型表、文字内容下限均为现状的 ≥3 倍。
2. **顶级前端**：参考 NYT / Reuters Graphics / FT / The Pudding / Pew / OECD 视觉密度与排版规范，全栈重构 CSS / 主题 / 导航 / 响应式 / 暗色模式。
3. **图表多样**：地图（choropleth / bivariate / cartogram / 点密度 / 流向）≥20 张，高级图（Sankey / ridgeline / parallel / radial / treemap / network / calendar heatmap / beeswarm）≥40 张。
4. **去 AI 痕迹**：所有注释、文案、caption、widget title 重写为研究语风；删除 "本图展示"、"通过本图我们可以看到"、"为用户提供" 等机器化句式。
5. **零版本号**：所有文件（R 脚本、CSS、HTML、Shiny 模块、注释）中不得出现 "v1"、"v2"、"v3"、"版本 X" 等版本标记。设计系统函数名中的 `_v3` / `_v2` 后缀全部移除或改为语义命名。
6. **可分享**：HTML 离线可读、Rmd 可直接 pandoc，GitHub Pages + shinyapps.io 同步部署。
7. **质量门禁**：每阶段过 `Rscript 构建.R quality`；新增导航一致性、地图覆盖、widget 类型多样性、响应断点四项检查。
8. **路径清晰**：所有路径中文化命名，与 README 同步；新增模块严格按 `NN_主题.R` 命名约定。
9. **不破坏既有功能**：升级以"加列不删列"为原则；旧 API 在新模块就绪后再删除。
10. **图表质量至上**：每张图必须满足本文档第 18 节"图表质量标准"的全部条目，不合格不得入库。
11. **解释充分**：每张图、每个 widget、每个 finding 必须有完整的上下文解释，读者无需翻阅其他材料即可理解含义。

## 18. 图表质量标准（强制，所有图必须满足）

本节定义所有静态图（PNG/SVG）和交互组件的最低质量要求。任何不满足以下条目的图表不得入库。

### 18.1 文字与标签

| 条目 | 要求 | 检测方式 |
|---|---|---|
| **零重叠** | 所有文字标签、轴标签、图例文字、注释之间不得有任何像素级重叠 | 使用 `ggrepel` 处理散点标签；facet 标题自动换行；轴标签旋转或缩写 |
| **最小字号** | 正文 ≥10pt，轴标签 ≥9pt，注释 ≥8pt，图例 ≥9pt | `theme_ghs(base_size = 12)` 保证 |
| **中英混排** | 中文使用 Noto Sans CJK SC / Source Han Sans SC / Microsoft YaHei；英文使用 Inter / Source Serif 4 | 字体回退链在 `ghs_register_fonts()` 中定义 |
| **数字格式** | 千分位逗号、百分比带 % 后缀、USD 带 $ 前缀、大数用 K/M/B 缩写 | 使用 `scales::label_*` 系列 |
| **轴标签** | 必须有单位说明（括号内），如 "人均卫生支出 (USD, 2023 不变价)" | 手动检查 |
| **标题层级** | title = 编辑性结论（一句话），subtitle = 数据范围与单位，caption = 数据源 + 样本量 | 使用 `labs_news()` 统一 |

### 18.2 图注（Caption）格式标准

所有图的 caption 必须遵循以下格式：

```
数据源: WHO GHED 2024-12 · 样本: N = {n} 国 · 时段: {year_start}–{year_end} · 单位: {unit} · 分析: 庄颂 (20241334)
```

**禁止出现的 caption 内容：**
- "本图展示了..."
- "数据来源于..."
- "图表由 R/ggplot2 生成"
- 任何版本号（如 "v2 设计"）
- 任何 AI 工具名称

### 18.3 色彩与对比度

| 条目 | 要求 |
|---|---|
| **WCAG AA** | 文字与背景对比度 ≥4.5:1（正文）、≥3:1（大字） |
| **色盲友好** | 所有分类色板通过 deuteranopia / protanopia 模拟测试；关键信息不仅靠颜色区分（辅以形状/线型/标签） |
| **语义一致** | 同一变量在所有图中使用同一颜色（如 GGHED 永远是 `#1d3f5f`，OOPS 永远是 `#a23b3b`） |
| **最大分类色** | 单图分类色不超过 7 种；超过时使用 highlight + grey 策略 |
| **渐变色** | 顺序数据使用 `palette_ghs_sequential()`；发散数据使用 `palette_ghs_diverging()` 并明确中点 |

### 18.4 布局与间距

| 条目 | 要求 |
|---|---|
| **宽高比** | 默认 10:6（横向）；地图 10:7；纵向排行 8:10；小倍数按内容自适应 |
| **边距** | plot.margin 至少 `margin(t=20, r=16, b=12, l=10)`；标题不得被裁切 |
| **图例位置** | 默认 top-left（水平排列）；地图用 bottom-right；小倍数可省略（用 facet 标题替代） |
| **网格线** | 仅保留水平主网格（浅灰 12% alpha）；竖网格默认关闭；散点图可开双向 |
| **轴线** | 仅保留 x 轴底线（0.45pt ink 色）；y 轴无线 |
| **facet** | strip 背景 8% alpha；strip 文字加粗；strip 间距 ≥4pt |

### 18.5 导出规格

| 格式 | DPI | 宽度 | 用途 |
|---|---|---|---|
| PNG | 400 | 12 inch | 静态页嵌入、课程提交（高清） |
| SVG | — | 12 inch | 网页缩放、打印 |
| PDF | — | 12 inch | 备用打印（可选） |

**设备选择：**
- PNG 优先使用 `ragg::agg_png`（原生字体支持，无豆腐块）
- SVG 优先使用 `svglite::svglite`
- 所有导出使用 `bg = "white"`

### 18.6 旧图升级要求

所有 94 张现有图必须在 B7 阶段完成以下升级：

| 升级项 | 具体操作 |

### 20.1 R 脚本注释规范

**文件头注释格式（唯一允许的格式）：**

```r
# =============================================================================
# 程序/NN_主题.R
# -----------------------------------------------------------------------------
# 一句话描述本模块的职责。
# =============================================================================
```

**禁止出现的注释内容：**

| 类别 | 示例（禁止） | 替代方式 |
|---|---|---|
| 版本标记 | `# v2 升级`、`# v3 新增`、`# Version 2.0` | 直接写功能描述 |
| AI 痕迹 | `# 由 Claude 生成`、`# GPT 辅助`、`# AI 建议` | 删除 |
| 教学语气 | `# 这里我们使用...`、`# 下面的代码将...` | 删除或改为 `# 目的：...` |
| 冗余说明 | `# 加载包`（在 library() 上方）、`# 定义函数` | 删除 |
| 占位符 | `# TODO`、`# FIXME`、`# XXX`、`# HACK` | 修复后删除 |
| 情感表达 | `# 完美！`、`# 搞定！`、`# 终于解决了` | 删除 |
| 时间戳 | `# 2026-05-12 新增`、`# 昨天修复` | 用 git log 追踪 |

**允许的注释风格：**

```r
# ---- 1. 国家元数据 ----------------------------------------------------------
```

### 20.2 图表标题与注释语风

**标题（title）：**
- 必须是编辑性结论，一句话概括图表传达的核心信息
- 禁止描述性标题（如 "各国人均卫生支出柱状图"）
- 正确示例：
  - "高收入国家人均卫生支出是低收入国家的 40 倍"
  - "2020 年 COVID 冲击使 68% 的国家政府卫生支出占比上升"
  - "撒哈拉以南非洲的外援依赖在 2015 年后持续下降"

**副标题（subtitle）：**
- 说明数据范围、单位、方法
- 格式：`{N} 国 · {year_start}–{year_end} · {unit} · {method}`
- 示例："195 国 · 2000–2023 · USD 2023 不变价 · 人口加权"

**图注（caption）：**
- 统一格式（见 18.2）
- 禁止任何主观评价或解释性文字

**注释（annotate）：**
- 仅用于标注关键数据点或事件（如 "2020 COVID-19"）
- 使用 `add_editorial_note()` 统一风格
- 字体：衬线体，半透明背景
- 禁止注释中出现 "可以看到"、"值得注意" 等句式

### 20.3 Shiny 模块文案

**模块 hero 区：**
- kicker：模块编号 + 英文主题词（如 "EQUITY"）
- title：中文主题名（如 "公平与不平等"）
- lead：一句话说明本模块分析什么问题、用什么方法、覆盖什么范围

**卡片标题：**
- 直接说明图表内容，不加修饰
- 正确："各大洲 OOPS 分布 (最新年)"
- 错误："为您展示各大洲 OOPS 的精彩分布"

**helpText / 提示：**
- 仅说明操作方式或数据口径
- 禁止 "本图展示"、"通过调整滑块您可以" 等句式
- 正确："拖动滑块选择年份范围"
- 正确："OOPS = Out-of-Pocket Spending，居民自付占当年卫生总支出的百分比"

### 20.4 静态页文案

**Finding 正文：**
- 每个 finding 的 lead 必须是一个可验证的数据主张（claim）
- 正文用 3–5 句话展开：数据范围 → 核心发现 → 异质性 → 局限
- 禁止 "综上所述"、"由此可见"、"不难发现" 等总结句式
- 结尾用 policy-take 给出政策含义（一句话）

**章节引言：**
- 每章开头 2–3 句话说明本章分析的问题和方法
- 禁止 "本章将为您介绍"、"接下来我们将" 等预告句式
- 正确："全球卫生支出的不平等程度在 2000–2023 年间经历了先升后降的倒 U 型轨迹。本节使用 Gini、Theil-T 和 Atkinson 三种指数量化这一趋势，并分解为组间与组内两个分量。"

### 20.5 版本号清除规则
