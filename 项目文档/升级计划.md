# 迭代计划摘要

本文件保留当前项目的维护方向。详细变更以 `项目文档/变更记录.md` 为准。

## 当前重点

1. 保持 Shiny、静态 HTML、课程 Rmd 和提交包之间的内容口径一致。
2. 保持页面风格克制、清晰、可读，避免装饰性渐变线、玻璃感和过重阴影。
3. 保证 dock、移动目录、图表索引、widget 懒加载和 Shiny 模块跳转可用。
4. 保证提交包根目录只有一个 `README.md` 文件，其余入口放入 `项目入口/` 与 `交付索引/`。
5. 通过 `Rscript 构建.R quality` 复核语法、图像、链接、widget、文本、secret、Shiny bundle 和 README 一致性。

## 后续维护

- 新增发现或图表时，先更新 `程序/21_static_showcase.R` 与方法手册，再重新生成 HTML/Rmd。
- 调整 Shiny 模块时，同步检查 `仪表盘/ui.R`、`仪表盘/server.R`、`仪表盘/模块/` 和 `仪表盘/www/`。
- 发布前依次运行 `Rscript 构建.R submission`、`Rscript 构建.R quality`、`Rscript 构建.R delivery`。
